# ACES media

Upload these files into this folder (`assets/aces/`). The ACES page picks them up automatically; until a file exists, a "coming soon" card is shown in its place.

| File | What it is | Also accepted |
|------|------------|---------------|
| `video.mp4` | the 1-minute video | `video.mov`, `video.webm` |
| `poster.jpg` | the poster | `poster.png`, `poster.jpeg`, `poster.webp` |
| `bot.jpg` | picture of the bot (also used as the project card thumbnail and the video cover) | `bot.png`, `bot.jpeg`, `bot.webp` |

Tips:
- Export the video as **H.264 MP4** — it plays in every browser. iPhone `.mov` files are often HEVC, which some browsers can't play.
- GitHub's web uploader accepts files up to 25 MB, so keep the video under that.
- File names are case-sensitive: `bot.jpg` works, `Bot.JPG` does not.
